# uniqpost

Сервис уникализации видео и автопостинга. Берёт видео (файлом или по ссылке), делает его уникальным и готовит к публикации по расписанию в Instagram, Facebook, VK и Telegram.

## Что уже есть

**Telegram-бот** (`bot.js`) — **@reunique_bot**
- принимает **видеофайл** или **ссылку** (TikTok, YouTube, Instagram, VK и др.)
- скачивает оригинал в лучшем качестве через `yt-dlp`
- предлагает: «🎨 Уникализировать» / «📤 Отправить как есть»
- при уникализации спрашивает **сколько версий** (1–5) и присылает столько уникальных вариантов
- уникализация через FFmpeg: метаданные, микро-смена скорости, яркости/контраста/насыщенности, шум, звук — каждый раз по-разному
- автоочистка временных файлов

**Превью интерфейса** (`preview.html`)
- лендинг + личный кабинет (статистика, аккаунты, очередь, расписание)
- тёмная тема, чёрный фон, синие неоновые акценты
- адаптив под мобильные

## Стек

- Node.js + `node-telegram-bot-api` (v2)
- FFmpeg — уникализация видео
- yt-dlp — скачивание по ссылкам
- systemd — запуск бота демоном

## Установка

```bash
npm install
```

Создать `.env` с токеном бота:

```
BOT_TOKEN=<токен от @BotFather>
```

Запуск:

```bash
node bot.js
```

## Структура

```
bot.js          — Telegram-бот уникализации
preview.html    — превью лендинга и личного кабинета
package.json    — зависимости
```
